# House Images

Place your house banner images in this directory with the following names:

- `stark.png` - House Stark banner/logo
- `baratheon.png` - House Baratheon banner/logo
- `greyjoy.png` - House Greyjoy banner/logo
- `lannister.png` - House Lannister banner/logo
- `targaryen.png` - House Targaryen banner/logo

The images will be displayed on the result page when students are assigned to their houses. If an image is missing, the system will automatically fall back to the emoji representation.
